# Cosmos Atlas

Cosmos Atlas is a Chinese-language immersive astronomy exploration website built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Three.js.

## Available pages

- `/`
- `/missions`
- `/cosmic-timeline`
- `/structure`
- `/starmap`
- `/gallery`

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run typecheck
npm run build
npm run visual:starmap
npm run visual:timeline-structure
```
